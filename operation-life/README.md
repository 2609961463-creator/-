# 自律行动 / Operation Life

受战术游戏赛季任务界面启发的个人任务与奖励工具，使用原创 CSS 与矢量地图，不包含游戏官方素材。纯 HTML、CSS、JavaScript，无需安装依赖。

## 运行

解压源代码，打开 `dist/index.html` 即可使用。推荐在固定地址运行本地服务器，避免浏览器对 file:// 存储的兼容差异：

```sh
python -m http.server 8080 --directory dist
```

打开 http://localhost:8080 。也可把 dist 目录部署到任意静态网站服务。无需数据库或 API 密钥。Google Fonts 可选，离线自动使用系统字体。

## 功能

- 每日任务、赛季目标，自定义分类、目标次数、计量单位和积分。
- 每次点击推进一次；达成目标后一次性发积分，防止重复领取。
- 每日任务按设备本地日期在零点重新开始；赛季目标按当前赛季的起止日期累计。
- 自定义奖励，可重复兑换，积分不足时不能兑换；兑换前需确认。
- 完成任务获得的积分同时计入累计经验，每 500 XP 升一级。兑换积分不会降低等级。
- 编辑或删除任务、奖励不会撤销历史积分和兑换记录。编辑已完成任务也不会重复发积分。
- 在「数据与赛季设置」中修改赛季起止日期会使用新的赛季进度；历史记录保留。相同起止日期视为相同赛季。结束日期用于展示，不会禁用任务。
- JSON 备份导入导出、清空数据、浏览器多窗口修改同步。
- 设置中可下载完整源代码。初次使用包含可自由修改和删除的示例。

## 数据说明

数据保存在当前浏览器、当前网站地址的 localStorage（键名 operation-life-v1），不会上传到服务器。不支持跨设备同步，也不会在后台发送提醒。浏览器隐私模式、禁用存储或清理网站数据会影响存档，请定期导出 JSON。换浏览器、域名或端口后，可通过导入备份迁移数据。建议只在一个窗口编辑，避免同时写入造成冲突。

赛季目标的推进由自己记录，不会自动关联每日任务。奖励需自行兑现。工具不验证现实任务是否完成。

## 修改代码

- dist/index.html：页面结构
- dist/style.css：样式、移动端适配
- dist/app.js：任务、积分、存储和导入导出逻辑

修改后刷新页面。此代码适合个人自用，可继续扩展。
